# augment.md — repository reference

A factual map of the codebase for contributors and coding agents. Keep it in sync when you change structure, schemas or invariants. Visual rules live in `DESIGN.md`; operational steps in `RUNBOOK.md`.

## Product in one paragraph

Based Math Game drills number-base conversion (zetamac-style: the answer submits itself the moment it is correct). Eleven topics in four tiers, five formats (sprint, speedrun, survival, daily, practice), custom drills, a Learn course, real-time multiplayer rooms (2–10 players, guests allowed) and leaderboards for registered accounts. Production: https://based-math-game.web.app.

## Stack

React 19 + TypeScript + Vite 8; Tailwind CSS 3 with CSS-variable tokens and Radix primitives (shadcn-style wrappers in `src/components/ui`); Framer Motion; React Router 7 (`createBrowserRouter`, every route lazy except Home); Firebase 12 (Auth, Realtime Database, Firestore, Hosting, optional App Check). Self-hosted variable fonts via `@fontsource-variable` (Newsreader, Schibsted Grotesk, Martian Mono). Vitest for unit and rules tests.

## Modes

- Ids: `${topicId}:sprint`, `${topicId}:speedrun`, `${topicId}:practice`, `survival`, `daily:YYYY-MM-DD` (UTC), `custom` (config travels separately).
- Topics: `nibbles`, `powers` (foundations); `bytes-bin`, `bytes-hex`, `octal`, `mixed` (core); `words`, `twos`, `bitwise`, `binary-add` (advanced); `applied` (colors & ASCII); `custom`.
- Ranked: every topic × {sprint, speedrun} (22), `survival`, and each daily. Practice and custom are never ranked.
- Sprint 60 000 ms, higher is better. Speedrun 15 correct, lower ms is better, +5 000 ms per skip. Daily 10 questions, lower ms, +10 000 ms per skip, one ranked attempt. Survival 3 lives, per-question clock `max(5000, 15000 − 200·i)` plus allowances.

## Invariants (read before changing)

- **Determinism:** question streams must stay identical across clients and versions. `src/game/__tests__` pins rng/hash/stream outputs; if a pinned test fails after a generator change, daily and multiplayer questions will differ between clients on different versions.
- **Rules ↔ limits:** `firestore.rules` constants must match `SCORE_LIMITS` / `RULES_LIMITS` (`src/data/limits.ts`); `src/data/limits.test.ts` enforces this.
- **RTDB rules are generated:** edit `scripts/build-database-rules.mjs`, then `npm run rules:db`. CI fails if `database.rules.json` is stale.
- **Guests** are Firebase anonymous users. They never write Firestore; their runs and settings live in localStorage and are imported on upgrade. Leaderboard writes require a non-anonymous token.
- **Timing** uses `performance.now()` and wall-clock deltas; multiplayer start is server time + 3 s (`serverTime.ts`).
- **Tokens only:** no raw Tailwind palette colors; see `DESIGN.md`.

## Data model

Realtime Database `rooms/{code}` (8 chars, no look-alike characters): `hostUid`, `status` (`waiting|playing|finished`), `mode {id, custom?}`, `maxPlayers` (2–10), `allowVisualAids`, `createdAt`, `lastActivityAt`, `startedAt`, `seed`, `slots/{0..9}` (seat → uid), `kicked/{uid}`, `players/{uid}` (`uid, displayName, slot, joinedAt, ready, round, score, correct, scoreMs, penaltyMs, finished, finishMs?, wins, lastWinRound?, scoreHistory/{i}, disconnected?, disconnectedAt?`), `chat/{uid}_{previous lastChatAt or 0}` (`senderId, displayName, message ≤300, timestamp == now, isSystem` host-only; one message per write), `lastChatAt/{uid}` (rate limit, written with each message), `winners {round, uids/{uid}}` (host-written at round end; a player's `wins` can only grow if named there). `presence/{uid}` is self-only. Stale rooms (6 h idle) may be deleted by any signed-in user.

Firestore: `users/{uid}` (`displayName, createdAt, settings`); `users/{uid}/runs/{id}` (create-only); `users/{uid}/dailyLocks/{modeId}` (`expireAt` only; created in the same batch as a daily leaderboard entry so each day allows one ranked attempt; TTL-deleted after the day closes); `userStats/{uid}` (`gamesPlayed, totalCorrect, totalDurationMs, lastPlayedAt, bests{modeId with ':'→'__'}`); `leaderboards/{modeId}/entries/{uid}` (`uid, displayName, score, correct, skipped, durationMs, accuracy, completed, updatedAt`; public read in pages ≤100; owner writes only when improved and plausible; daily entries need all 10 questions, today's UTC date and a new daily lock). Indexes in `firestore.indexes.json`.

## Hosting

`firebase.json`: SPA rewrite, strict CSP (`script-src 'self'` plus Google/Firebase hosts — no inline scripts), HSTS, X-Frame-Options DENY, COOP `same-origin-allow-popups`, immutable caching for `/assets/**` and fonts, `no-cache` elsewhere. `public/sw.js`: network-first navigations with offline fallback, cache-first only for hashed assets, never caches cross-origin or `/__/` requests; registered in production only.

## Commands

`npm run dev` · `npm run build` · `npm run lint` · `npx tsc --noEmit` · `npm test` · `npm run test:rules` (emulators) · `npm run rules:db`. Emulators: set `VITE_USE_FIREBASE_EMULATORS=true` (ports overridable with `VITE_EMULATOR_*`).
